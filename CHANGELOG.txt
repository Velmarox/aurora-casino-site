AURORACASINO SITE - CHANGELOG
Versioning scheme: v#.#.#-[stage] (semver)
Patch = fixes | Minor = new content (patch resets) | Major 0 until launch (v1.0.0)
Stages: -alpha → -beta at feature-complete → -rc1 when launch-ready → v1.0.0 gold
A bump renames the build root folder and adds an entry here; working files keep their names.
Archived (outgoing-version) copies live in _version_archive/, never in the build folder.

Folder organization (Firebase-native repo):
  public/            Hosting deploy root — index.html, Css/, Js/, Assets/  (lowercase "public" is Firebase's convention)
  Docs/01_Design_System/  tokens (Aurora_Tokens.css) + token reference doc
  Docs/02_Assets/         master brand marks + gallery photography (public/Assets holds deploy copies)
  Docs/02_Assets/Video/   hero video poster master (the .mp4 deploy copy lives in public/Assets/Video/)
  Docs/02_Assets/Promos/  promo graphics — not deployed until a promos page exists
  Docs/02_Assets/Team/    staff photography — not deployed until a team page exists
  Docs/04_Notes/          audits and decision records
  _version_archive/       frozen copies of outgoing versions — never edit
  firebase.json, .firebaserc, .gitignore, README.md, CHANGELOG.txt at the root
